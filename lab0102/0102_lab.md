# Лабораторная работа №1

## Тема
Установка и настройка Git, создание SSH-ключа, работа с удалённым репозиторием.

## Цель работы
Изучить основы системы контроля версий Git, освоить настройку Git, создание SSH-ключа, работу с локальным и удалённым репозиториями.

## Оборудование и программное обеспечение
- Операционная система Windows
- Git Bash
- Git
- GitHub
- SSH

## Ход выполнения работы

### 1. Установка Git
Установлен Git для Windows. Проверена версия командой:

`git --version`

### 2. Настройка Git
Настроены имя и электронная почта пользователя с помощью команд:

`git config --global user.name`

`git config --global user.email`

### 3. Создание SSH-ключа
Создан SSH-ключ типа Ed25519. Публичный ключ добавлен в настройки GitHub.

### 4. Проверка SSH-подключения
Выполнена проверка подключения командой:

`ssh -T git@github.com`

Подключение прошло успешно. GitHub подтвердил аутентификацию пользователя.

### 5. Создание локального репозитория
Создан каталог проекта KARAAV. В каталоге инициализирован локальный Git-репозиторий.

### 6. Создание удалённого репозитория
На GitHub создан удалённый репозиторий KARAAV. Локальный репозиторий связан с удалённым с помощью команды `git remote add origin`.

### 7. Создание коммитов и отправка изменений
Созданы файлы README.md и .gitignore. Изменения добавлены в индекс, сохранены коммитами и отправлены на GitHub командой `git push`.

### 8. Подготовка отчёта
Создан каталог lab0102, в котором размещены README.md, данный файл отчёта и папка img для скриншотов.

## Результат работы
Создан локальный Git-репозиторий KARAAV, настроено SSH-подключение к GitHub, создан удалённый репозиторий и выполнена отправка изменений.

Ссылка на репозиторий: https://github.com/rusty126/KARAAV

## Вывод
В ходе лабораторной работы изучены основные возможности Git. Получены практические навыки настройки Git, создания SSH-ключа, инициализации локального репозитория, выполнения коммитов и отправки изменений в удалённый репозиторий.
